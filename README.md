# QR Code Generator

A simple and interactive **QR Code Generator** built using HTML, CSS, and JavaScript. This project allows users to generate QR codes from text or URLs, making it easy to share information through scannable codes.

## Overview

The QR Code Generator provides a user-friendly interface where users can enter text or a website URL and generate a corresponding QR code.

The project demonstrates the use of frontend web technologies to build an interactive web application without requiring a backend.

## Tech Stack

- **HTML5** – Structures the web page and input elements.
- **CSS3** – Styles the interface and provides a responsive layout.
- **JavaScript** – Handles user interactions and QR code generation.

## Features

- Generate QR codes from text or URLs.
- Simple and user-friendly interface.
- Interactive input and generation controls.
- Instant QR code generation, depending on the implementation.
- Lightweight frontend application.
